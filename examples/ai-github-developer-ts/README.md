# AI GitHub Developer (TypeScript / E2B)

Replication of the E2B Python AI GitHub Developer in TypeScript, demonstrating automated issue ingestion, repository cloning, and code modifications inside an isolated E2B Cloud Sandbox.

## Prerequisites
- Node.js 18+
- E2B API Key (`E2B_API_KEY`)
- GitHub Personal Access Token (`GITHUB_TOKEN`)

## Usage
```bash
npm install
npm start
```
